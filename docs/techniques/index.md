# Techniques & Capacités

<span class="rule-eyebrow">NARUTO LEGACY · ARCHIVES DES ARTS SHINOBI</span>

Bienvenue dans le répertoire des techniques et capacités de **Naruto Legacy**.

Cette section rassemble les arts shinobi accessibles aux personnages : spécialisations, natures élémentaires, techniques de Kekkei Genkai, capacités de clan, Kinjutsu et passifs. Les techniques sont classées selon leur catégorie et leur palier de progression afin de faciliter leur consultation.
